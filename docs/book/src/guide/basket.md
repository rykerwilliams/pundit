# The basket

The basket makes one film out of clips from several matches — every goal you
conceded from corners this season, say.

1. In any project, right-click a clip and choose **Add to basket**.
2. Open another match and add more. The basket keeps them, in the order you
   added them, across projects and across restarts.
3. Press **Basket…**, beside **Export…**. It works with no project open.
4. Name the film, choose the **Quality**, and press **Start**.

The film goes into a `pundit` folder in your videos folder, never over an
existing one: a name already taken gets ` (2)`.

## What each piece carries

Each piece draws its own match's scoreboard and clock, and its caption bar reads
`<match> | <clip> | <tags>`. The film's chapters are its pieces. Every piece is
mixed at the same default volumes, so the level does not jump between matches;
**Mute source audio** leaves the game's sound out of all of them.

## When a piece cannot be used

A row says so when its project cannot be read or its clip has gone. The footage
itself is only checked when you press **Start**, so a row that looks fine can
still be refused then — the message above the button names the folder. Use the
row's buttons to reorder or remove pieces.
